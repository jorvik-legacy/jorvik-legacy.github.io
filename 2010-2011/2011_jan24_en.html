Test Rider – Sign Up Open!

You can now apply to become a Test Rider and help us make Star Stable the best horse riding game ever. As a Test Rider you get to play the game before everyone else, and try out everything before the game is released. Click the image at the right side of the web page to read more.

Do you want to help us make Star Stable the best horse game ever?
Sign up for the Test Rider programme!

If you sign up you might be selected to try out Star Stable before it is released. Even though it is a while before Star Stable is released, the Development Team is hard at work right now creating the game. They need your help to make sure that everything works in the world of Jorvik when the game is released.

What does it mean to be a Test Rider?

  • You get access to Star Stable before everyone else.
  • You can (and we hope you do) report in any bugs or problems you find.

As the game is in development, there are several things that can happen during testing, and that you should be prepared for.

  • The game is reset, meaning that you loose your character and horse and have to start over again
  • The game becomes unavailable for long periods of time.
  • The game behaves strangely or crashes.
  • Quests, people, and locations change places, disappear, or new ones appear in the world.
  • Features are limited or unavailable. But as we get closer to release, more and more features will become available.

Is there anything else I should know?

  • The number of Test Riders selected will be very small to begin with but more will be invited as we get closer to release. So don’t be dissapointed if you are not selected at first.
  • You will receive an e-mail when and if you are selected.
  • Don’t sign up more than once!
  • During testing the game will only be available in English so you must understand English to participate!
